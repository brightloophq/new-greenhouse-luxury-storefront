# Design Philosophy

Every page should feel like:

Walking into a luxury flower boutique.

The site should never feel like a normal ecommerce template.

Follow the non-negotiable design law in `docs/LUXURY_PRINCIPLES.md` on every screen
(one focal point per viewport, ≤3 primary actions, never two buttons side by side,
white space is content, remove more than you add).

---

# Images

Images are critical.

Whenever current images are poor:

- regenerate
- upscale
- crop correctly
- resize
- improve composition

Prefer cinematic floral photography.

Avoid stock-photo appearance.

---

# Layout Rules

No oversized sections.

No giant buttons.

No excessive padding.

Keep content readable.

Use premium spacing.

Desktop-first.

Perfect mobile experience.

---

# Components

Always create reusable components.

Never duplicate UI.

Follow atomic design.

# Performance
