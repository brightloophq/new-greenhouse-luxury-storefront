# public/images

Brand imagery for The New Greenhouse, organised by art-direction category.
Files are served at `/images/<category>/<file>`.

**Do not add ad-hoc images here.** Every asset — exact filename, dimensions,
aspect ratio, alt text, placement, and its AI generation prompt — is specified in
[`docs/ASSET_MANIFEST.md`](../../docs/ASSET_MANIFEST.md). Generate against that
manifest, run the compression checklist (§E), then drop the file into the matching
folder.

Folders: `hero/ wholesale/ supplies/ weddings/ corporate/ delivery/ heritage/
collections/ mobile/`. `.gitkeep` files hold empty folders until assets land.

Direction: black `#090909` · gold `#C8A96A` · ivory `#FAF8F4` · green `#4D6A50`.
Premium wholesale florist · editorial · authentic Kingston, Jamaica.
Collection-card images go to **Shopify** (CDN), not hardcoded in the repo.
